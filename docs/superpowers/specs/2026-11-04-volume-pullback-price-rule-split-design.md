# 放量回踩系列价格规则拆分：趋势线版去幅度限制 / 多空线版对称贴线带

日期：2026-11-04。状态：已实现（TDD）。**2026-11-05 用户确认 ±2% 定稿**——8/9/10 三个月
正式回测验证：±1% 收窄三个月胜率全部更低（36.7<40.4、28.1<29.6、23.9<26.0），减亏
纯属缩量且砍掉盈利月弹性，不采用；多空线版维持 ±2% 对称带。

## 背景与需求（用户 2026-11-04 口述确认）

放量回踩两策略原共用同一价格规则（2026-09-18 口径）：`收盘 ≥ 目标线` + `|收盘−目标线|/目标线 < 2%`。
复核中发现：两条件叠加后 `abs()` 恒为恒等变换（能走到贴线判断时收盘−目标线必非负）——
绝对值从未生效，贴线带只剩上侧 `[线, 1.02×线]`，收盘轻微破线（线下 2% 以内）的回踩永远选不出。
用户确认两策略的价格规则本就应当**不同**（趋势线版上限当天两次收敛，最终口径如下）：

| 策略 | 价格规则（最终口径） | 相对旧口径的变化 |
|---|---|---|
| `volume_pullback_trend` 放量回踩趋势线 | **短期趋势线 ≤ 收盘 ≤ 短期趋势线×(1+1%)**（上限含等于） | 上侧贴线带从 2% 收紧为 1%；下限不变（破线即排除） |
| `volume_pullback_bullbear` 放量回踩多空线 | **\|收盘 − 多空线\| / 多空线 ≤ 2%**（对称贴线带，线上线下皆可） | 去掉「收盘≥多空线」——轻微破线回踩入选；含等于（"2%以内都可以，等于也可以"） |

其余条件不变：流通市值 ≥ 50 亿 + 短期线 > 多空线（趋势结构）+ 20 日内存在倍量柱。

## 影响

- 两策略信号集合都会变化（趋势线版上侧收紧为 1% 带、多空线版下限放开）；
  **依赖这两个策略的历史选股与回测结果不可比，需重跑**
- 恰好等于边界（收盘=线、=1%、=2%）在浮点下不可判定（`x×1.02` 类舍入方向不确定），
  实现按含等于处理；测试用 ±1bp 验证边界两侧

## 实现

- `volume_pullback.py`：基类抽 `_price_ok(close, line)`（两策略唯一分叉点），
  趋势线版 `line <= close <= line×(1+TREND_MAX_ABOVE_DEV)`（1%），
  多空线版 `abs(close−line)/line <= PULLBACK_MAX_DEV`（2%）；共享骨架不变
- `selectors/__init__.py`：两策略 description 同步新口径（前端下拉展示）

## 测试（8→13 项）

- 翻转：远离线上方 6% → 双双不选（趋势线版超 1% 上限、多空线版超 2% 带）；
  收盘 9.7（多空线下方 1.3%）→ 趋势线版不选、多空线版**选中**；
  贴线但破线 0.5% → 多空线版选中、趋势线版不选
- 边界：趋势线版线上 1bp / 高 0.99% 选中，线下 1bp / 高 1.01% 排除；
  多空线版 ±1.99% / ±2.01% 四象限（锁对称带与含等于）
- 不变回归：双贴同选、仅贴 DUO 区分场景、无倍量不选、DUAN<DUO 不选、市值门槛、
  空数据、倍量柱窗口 ±20 日、除权前复权复原
